# Simple Finances

Fabric-мод для Minecraft **1.21.1** с простой экономикой: монеты, электронный счёт, кошелёк, переводы между игроками, обмен коллекционных монет, общая коллекция сервера и админ-панель.

## Требования

- Minecraft 1.21.1
- Fabric Loader 0.16+
- Fabric API
- Java 21

Мод нужен **и на сервере, и на клиентах**: кошелёк — это собственный GUI, а операции синхронизируются по сети.
Сервер в offline mode поддерживается: счета привязаны к UUID, для офлайн-игроков используется стандартный offline-UUID.

## Сборка

```bash
./gradlew build
```

Готовый jar: `build/libs/simple-finances-1.0.0.jar`.

## Установка

1. Положите jar в `mods/` на сервере и у клиентов.
2. Установите Fabric API.
3. Запустите сервер.

## Использование

- **B** — открыть кошелёк (клавишу можно переназначить в настройках управления).
- `/wallet` — открыть кошелёк.
- `/balance` — показать баланс в чате.
- `/pay <игрок> <сумма>` — перевод без открытия GUI.

### Кошелёк

- **Положить наличные** — забирает монеты из инвентаря и зачисляет их на счёт. Пустое поле = положить всё. КД пополнения по умолчанию 5 минут.
- **Снять наличные** — выдаёт монеты в инвентарь (если места нет — выбрасывает рядом).
- **Перевод игроку** — комиссия 2% (настраивается админом), платит отправитель.
- При поступлении перевода или пополнении счёта появляется тост в стиле достижения.

### Монеты

- `Монета` — номинал 1.
- `Монета (50)` — номинал 50.
- В сетке крафта: **50 монет → 1 монета (50)**, и наоборот **1 монета (50) → 50 монет**.
- Монеты выпадают при смерти (обычное поведение предметов), но баланс на счёте при смерти не меняется.
- У физических монет нет владельца/NBT — отследить их нельзя.

### Коллекционные монеты

- Три тира: **рубин** (топ), **сапфир** (средний), **жемчуг** (низший).
- Не создаются крафтом. Их можно обменять на деньги, но только один раз — после обмена монета уходит в общую коллекцию сервера.
- Выдаются только админом через панель, с описанием (за что и когда) и датой.
- В тултипе видно тир, описание, дату и получателя.
- При выдаче в чат приходит уведомление с тиром и получателем (имена или «всем игрокам»), а получатели видят тост.

### Монеты серий

- Семь серий: **Океаническая**, **Эндовая**, **Испытаний**, **Вардена**, а также адские — **некротитовая**, **пиглинская** и **адская**.
- У обычных серий три состояния: **грязная** (500), **немного грязная** (5 000) и **идеальная** (12 500). Адские монеты всегда идеальные.
- Обычные серии добываются так: в сундуках подходящих структур с шансом **1%** лежит **сгусток** (океанический — затонувшие корабли и подводные руины, а также вылавливается рыбалкой с шансом **0,5%**; эндовый — энд-сити; испытаний — все сундуки камер испытаний, включая награды; вардена — древний город). Промойте сгусток в котле с водой (ПКМ) — получите монету: 80% грязная, 19,9% немного грязная, 0,1% идеальная. Вода не расходуется.
- Адские монеты: пиглинская — в сундуках бастионов (1%), адская — в сундуках крепости Нижнего мира, включая мост (1%), некротитовая — из древних обломков (5%).
- Обмен серийных монет не берёт комиссию: деньги сразу зачисляются на баланс, а монета попадает в общую коллекцию сервера.

### Обмен и коллекция

- Вкладка **Обмен** превращает коллекционную или серийную монету в деньги на счёте: рубин — **25 000**, сапфир — **10 000**, жемчуг — **1 000**; серийные — по состоянию.
- Монету нужно выбрать в списке и нажать «Конвертировать». Деньги зачисляются сразу, монета из инвентаря исчезает.
- После обмена монета навсегда попадает в **общую коллекцию сервера** — забрать её обратно нельзя.
- Админ может выдать коллекционную монету любому игроку через вкладку **Монеты** (по нику или всем онлайн); когда игрок конвертирует её, запись попадёт в общую коллекцию.
- Вкладка **Коллекция** показывает монеты сервера, листается страницами. При наведении видно, кто добавил монету, за что она была выдана, когда, кому и когда попала в коллекцию. Кнопка «Обновить» подтягивает свежие записи.
- Коллекция общая для всех игроков и сохраняется вместе с экономикой.

## Админ-панель

Доступна игрокам с правами оператора (permission level 2). Открывается той же клавишей **B** или командой `/finances admin`. К обычным вкладкам добавляются:

- **Операции** — последние 150 операций: кто, сколько, куда и когда перевёл/снял/положил; комиссии, блокировки, выдача коллекционных монет.
- **Монеты** — выбор тира, описание, кнопка «Сегодня» (подставляет текущую дату), получатели (список или все онлайн), создание и выдача.
- **Блокировки** — блокировка счёта на заданное время с причиной, список заблокированных счетов и разблокировка. Заблокированный игрок получает тост и не может пополнять, снимать и переводить; его счёт также не может принимать переводы.
- **Настройки** — комиссия перевода (0–50%) и КД пополнения (0–86400 секунд).

Команды для админа:

```
/finances admin
/finances fee <0-50>
/finances cooldown <0-86400>
/finances block <игрок> <минуты> [причина]
/finances unblock <игрок>
```

## Хранение данных

Все счета, настройки, журнал операций и коллекция сервера хранятся на сервере в
`<мир>/data/simplefinances.dat`. Данные переживают перезапуск сервера.

## Примечания

- Сумма одной операции ограничена 1 000 000 монет.
- Перевод на имя игрока, который ещё ни разу не заходил, создаёт счёт по offline-UUID: деньги будут ждать его при входе. При первом входе имя сопоставляется без учёта регистра (`alice` = `Alice`), но счета игроков, которые уже заходили, не сливаются.
- У монет собственные текстуры: `coin.png`, `coin50.png`, `coin-c-ruby.png`, `coin-c-saphire.png`, `coin-c-pearl.png`.
